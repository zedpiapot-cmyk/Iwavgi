# 144 reasons para mas madami Kesa sayo

This is a GitHub Pages-ready static website.

## Files
- `index.html` = the complete website
- `your-universe.mp3` = YOU add your legally obtained copy of the song
- `bawat-daan.mp3` = YOU add your legally obtained copy of the song

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Upload the two MP3 files if you have the right to use them.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Open the generated GitHub Pages URL.

GitHub Pages looks for `index.html` as the entry file. Publishing can take a few minutes.

## Music
The site starts `your-universe.mp3` immediately after the visitor taps **Open Me**. When it ends, `bawat-daan.mp3` starts.

The music files are not included in this package because they are copyrighted recordings. Do not upload music unless you have permission/a license to use it.

## Photos
For the permanent version, replace the four photo placeholders in `index.html` with image files in the repository, or change the HTML to reference your own images.
